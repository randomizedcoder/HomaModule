# Homa Nix flake — quick start

A modular Nix layer over the Homa kernel module: dev shell, debug/release derivations of the
module and user-space tools, a microVM that actually loads `homa.ko`, tiered static analysis,
and (de)serialization-focused fuzzing.

- **Design & rationale:** [`docs/DESIGN.md`](docs/DESIGN.md)
- **Live build status:** [`docs/STATUS.md`](docs/STATUS.md)

## Commands

```sh
nix develop                          # dev shell (toolchain + analysis tools)

nix build .#homa-module              # homa.ko (release) against the pinned kernel
nix build .#homa-module-debug        # homa.ko (debug: -g -O1)
nix build .#homa-module-6_12         # against the 6.12 LTS kernel (drift fallback)
nix build .#homa-utils[-debug]       # user-space tools (util/); -debug adds ASan
nix build .#homa-tests               # build + run the unit tests (ASan)

nix run   .#homa-microvm-test        # boot a microVM, insmod homa.ko, smoke-test it
nix run   .#homa-microvm-test-debug  # ... under a KASAN/KMEMLEAK kernel

nix build .#homa-image[-debug]       # OCI userspace image (docker load < result)

nix build .#analysis-quick           # python + shell + clang-format (no kernel needed)
nix build .#analysis-standard        # + cppcheck + clang-tidy
nix build .#analysis-deep            # + sparse (endianness) + smatch

nix build .#fuzz                     # standalone wire-decoder + selftest harnesses
FUZZ_TIME=300 ./result/bin/run-fuzzers   #   ... run them for 5 minutes
nix build .#fuzz-run                 # bounded run -> summary.txt / count.txt / crashes
nix build .#fuzz-deep                # fork-mode + dictionary + crash dedup
nix build .#fuzz-cov                 # coverage of the wire decoder
nix build .#fuzz-selftest            # canary gate (fails if the harness is vacuous)
nix build .#fuzz-mock                # kernel-mock harnesses (Focus A/B; best-effort)

nix flake show                       # list every output
nix flake check                      # run the checks
```

## Module map

| File | Concern |
|---|---|
| `kernel.nix` | kernel selection (`linux_latest`) + `KDIR` + LTS matrix |
| `packages.nix` | toolchain inventory (build deps, dev/analysis tools, python env) |
| `env-vars.nix` | dev-shell environment fragment |
| `module.nix` | `homa.ko` derivations (debug/release + matrix) |
| `userspace.nix` | `util/` tools + `test/` unit harness |
| `devshell.nix` + `shell-functions/` | the dev shell |
| `oci.nix` | user-space OCI image |
| `microvms/` | microVM guest + orchestrator (loads/tests `homa.ko`) |
| `analysis/` | tiered static analysis (quick/standard/deep) |
| `fuzz/` | libFuzzer harnesses focused on wire (de)serialization |

Reports generated by the analysis/fuzzing runs live in [`../analysis-reports/`](../analysis-reports/).
